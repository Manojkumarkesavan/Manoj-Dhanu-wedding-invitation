# Manoj-Dhanu-wedding-invitation

# Tamil wedding invitation (static, GitHub Pages)
**Edit:** `js/config.js` – dates (ISO with +05:30), venues, map embed URL (Google Maps > Share > Embed, copy `src`), WhatsApp number (digits with country code, e.g. 919876543210), feature on/off. Tamil/English text is in `T` at the top of `js/main.js`.
**Photos:** put `hero.jpg` in `assets/images/`, gallery photos in `assets/images/gallery/` (list them in config). Compress to ~300 KB each.
**Music:** add a track you own or have licence for as `assets/audio/wedding-bgm.mp3`. It starts only after the guest taps Open or the ♪ button.
**Personal links:** `https://USERNAME.github.io/REPO/?guest=Family%20Name`
**Deploy:** create repo > upload files > Settings > Pages > Deploy from a branch > main / root > Save.
Gallery protections are deterrents only; photos can still be saved.
